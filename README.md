# HoloVision 2

### AI-Powered Visual Assistance Prototype

## About the Project

HoloVision 2 is a web-based visual assistance prototype that uses a webcam and AI-based object detection to interpret the surrounding environment.

## Problem Statement

Understanding nearby objects and estimating their distance can be challenging. HoloVision 2 explores how computer vision can provide useful visual information through a browser-based application.

## Features

- Webcam-based visual monitoring
- AI-based object detection
- Approximate distance estimation
- Prototype-level fall detection
- SOS alert functionality
- WebRTC-based video communication support

## Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- COCO-SSD
- WebRTC
- Python

## How It Works

The application accesses the webcam, processes visual input and uses object detection to identify objects. It also provides approximate distance estimation and other prototype features.
